# red-gate

《红色的门和杀人鬼的钥匙》 / *The Red Doors and the Killer's Key* for
[kwibaka-boardgame-platform](https://github.com/kwibaka-games/boardgame-platform).

3–8 player hidden-information card game. Players open numbered red doors in a
mansion, collect silver keys, and try to escape before the murderer kills
everyone. The host selects any subset of the expansion cards before starting.

- Spectators see every card and identity, but cannot chat.
- The holder of 沉默的毒蛾 cannot chat; this is enforced by the host platform.
- Secret keys/roles are only visible to their owner and spectators.
